Privacy: text you check is sent to Anthropic's API (Claude) over HTTPS. Don't use it on patient-identifiable or other confidential information unless your organization permits it. Your API key is stored only in this browser profile.

Rephrasing styles

How to use

  • Click into any text box — a small W button appears. W = fix grammar & spelling, ✎ = rephrase.
  • Keyboard: Alt+Shift+G fix · Alt+Shift+R rephrase (change at chrome://extensions/shortcuts).
  • Or right-click inside a text box → Fix grammar & spelling / Rephrase…
  • Select part of the text to check only that part; otherwise the whole field is checked.
