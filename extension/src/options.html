How to use

  • Click into any text box — a small P button appears. P = fix grammar & spelling, ✎ = rephrase.
  • Keyboard: Alt+Shift+G fix · Alt+Shift+R rephrase (change at chrome://extensions/shortcuts).
  • Or right-click inside a text box → Fix grammar & spelling / Rephrase…
  • Select part of the text to check only that part; otherwise the whole field is checked.
